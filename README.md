# ⚔️ GitHub Profile Finder

A web application that allows users to search for GitHub profiles and view public profile information using the GitHub API.

## 🚀 Features

- Search for GitHub users
- Display profile information
- Display profile avatar
- Display repository count
- Display follower count
- Display following count
- Display user bio
- Link directly to the GitHub profile
- Handle invalid usernames
- Responsive design

## 🛠️ Technologies

- Python
- Flask
- HTML5
- CSS3
- GitHub REST API
- JSON
- Git & GitHub
